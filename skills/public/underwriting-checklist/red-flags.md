# Red Flags in Underwriting

## Automatic Escalation Required

The following conditions require immediate escalation to senior credit before proceeding:

### Financial Red Flags

| Flag | Threshold | Action |
|------|-----------|--------|
| Historical DSCR | Below 1.0x | Senior credit review |
| Negative working capital | Any period | Document cause and remedy |
| Audit opinion qualified | Material uncertainty | Senior credit + audit committee |
| Related party transactions | >10% of revenue | Enhanced disclosure required |
| Off-balance sheet obligations | Any material amount | Full consolidation analysis |

### Operational Red Flags

| Flag | Threshold | Action |
|------|-----------|--------|
| Customer concentration | >25% single customer | Diversification covenant or decline |
| Supplier concentration | Single source for critical input | Contingency plan required |
| Key person dependency | Identified critical person | Key person life insurance |
| Regulatory action | Pending or recent | Legal review required |

### Integrity Red Flags

These conditions result in automatic decline unless waived by Credit Committee:

- [ ] Discrepancies between financials and tax returns (>5% variance)
- [ ] Undisclosed related parties discovered
- [ ] Prior fraud convictions (any principal)
- [ ] Willful tax evasion history
- [ ] Sanctions list hit (OFAC, EU, UN)
- [ ] Structuring to avoid reporting requirements
- [ ] False statements on application

### Collateral Red Flags

| Flag | Threshold | Action |
|------|-----------|--------|
| Appraisal vs. purchase price | >15% variance | Second appraisal |
| Environmental Phase I | RECs identified | Phase II required |
| Title defects | Any material defect | Title insurance + cure |
| Prior liens undisclosed | Any amount | Full search + explanation |

## Escalation Procedures

### Level 1: Credit Manager
- Single ratio below threshold with explanation
- Minor documentation deficiencies
- Standard covenant modifications

### Level 2: Senior Credit Officer
- Multiple ratios below threshold
- Customer/supplier concentration
- Related party transactions
- First-time audit qualification

### Level 3: Credit Committee
- DSCR below 1.0x
- Integrity concerns
- Policy exceptions
- Loans above individual authority limits

## Documentation Requirements

When escalating, include:

1. **Issue Summary**: Clear statement of the red flag
2. **Context**: How it was discovered and timeline
3. **Impact Assessment**: Financial and operational implications
4. **Mitigants Proposed**: How the risk can be reduced
5. **Recommendation**: Approve with conditions, decline, or request more information
