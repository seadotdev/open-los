# Principles and Ideas

## 1. CLI-First, Agent-Driven Interaction

The primary interface and interactions should be via tools like Claude Cowork and ChatGPT web, where they call the CLI. The CLI is robust and provides clear confirmation before doing anything destructive.

## 2. Web Interface as Activity Hub

The web interface is primarily for comforting traditional users. Initially it serves as an activity feed and "hub of activity" — algorithmically formulated to surface what users might find interesting. Users can comment like a social feed.

## 3. Highly Customisable UX

The UX is very customisable. Users can modify any page and an agent will create their modifications. They can share or publish these. Changes are reviewed by an agent to make sure they are sensible. Changes to data storage, data model, and backend are less flexible.
