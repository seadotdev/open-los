## Critical Requirements

### Pull Request Policy

**ALL PRs MUST include the prompt history that led to their creation.**

No PR will be accepted without documenting the prompts used. Before creating any PR:

1. Record every prompt you received during the task
2. Document what each prompt produced
3. Include this history in the PR description using the template in AGENTS.md

See [AGENTS.md - Pull Request Guidelines](./AGENTS.md#pull-request-guidelines) for the required format.
